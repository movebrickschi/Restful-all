# Restful-all v1.3 Release Train

> v1.3 是 Restful-all 从「路由插件」迈向「一站式 API 开发套件」的跨越式版本。  
> 为控制风险、保证质量，本次大版本采用 **Release Train 模式**：以 v1.3.0 → v1.3.1 → v1.3.2 → v1.3.3-GA 四个小迭代交付，合计跨度 12~14 周。

## 一、版本主题

| 主题 | 内容 |
| --- | --- |
| 一句话 | 在 IDE 内完整替代 Postman，并通过 AI + 团队协作建立 Pro 价值 |
| 形象 | 路由插件 → 一站式 API 工作台 |
| 商业 | 引入三档订阅：Free / Pro $4.99 月 / Team $9.99 seat·月 |

## 二、Release Train 节奏

```
v1.3.0  (4 周)  基础拉新     — 环境变量 / cURL / Auth / i18n / 骨架重构
v1.3.1  (3 周)  AI 首领 + 迁移护航 — Collection / Swagger / Postman 导入 + AI 智能参数填充
v1.3.2  (4 周)  接口测试专业化  — 响应高级查看 / 断言 / 历史增强 / AI 诊断 + 用例
v1.3.3  (4 周)  Team 启动 + GA  — 云同步 / 共享 / Mock / 文档同步 / 压测 / 用例编排 / GA
```

## 四、v1.3.0 骨架重构（必先完成）

以下三项基础设施在 v1.3.0 必须先于业务功能落地，因为后续 23 项功能均依赖：

| 模块 | 目的 |
| --- | --- |
| `service/EnvironmentService` | 环境变量与 `${var}` 替换的集中入口 |
| `service/SecretStorageService` | 包装 IntelliJ `PasswordSafe`，避免 Token/密码落明文 |
| `service/RequestExecutor` | 从 `ApiDebugPanel.sendRequest()` 抽取的请求调度器；统一接入 env / auth / AI / 压测 / Mock / 编排 |
| `service/ProFeatureGate` | 订阅档位识别 + 升级引导弹窗的唯一入口 |

## 五、计量与上线门槛

- v1.3.0 上 Marketplace 时 Pro/Team 入口可见但置灰，仅 v1.3.1 起开启支付
- 每个小版本独立 QA 门槛 + CHANGELOG 条目
- v1.3.3-GA 上线前进行公测周招募，至少收集 30 份用户反馈

## 六、回滚预案

- 任意一个小版本严重 bug → 立即在 Marketplace 下架对应版本，回退到上一个 GA 标签
- SettingsState 字段升级遵循「只加不删」规则，新字段提供默认值；卸载 / 降级时旧版本能继续读
- 启动失败时通过 `app-internal-state.db` 检测异常并提示用户「重置 v1.3 配置」一键回滚

## 七、参与方式

- 路线图变更：提 PR 改本文件
- 试用反馈：GitHub Issue + 模板 `[v1.3-beta]`
- Pro 功能 prompt 优化：欢迎社区贡献到 `docs/prompts/`
